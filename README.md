# Café Lyria — Premium One-Page Website

Open `index.html` in a modern browser. The site is self-contained except for Google Fonts and remote Unsplash imagery.

Included:
- Responsive desktop/tablet/mobile layout
- Sticky glass navigation + mobile menu
- Animated hero, floating orbs and subtle mouse parallax
- Scroll-triggered reveals and staggered cards
- Animated counters
- Menu, gallery/portfolio, reviews carousel, CTA and contact form
- Loading animation
- Lenis smooth scrolling with autoRaf, inertia, and anchor alignment
- Customer Table Reservation system with instant receipt generation
- Owner Admin Portal (`admin.html`) with real-time floor plan booking management, filters, metrics & CSV export
- Accessible labels and `prefers-reduced-motion` support
- Semantic HTML and SEO description

Replace the Unsplash URLs with Café Lyria's own approved photography before production.
The contact form currently shows a local success state; connect it to your preferred form/email backend for real submissions.
